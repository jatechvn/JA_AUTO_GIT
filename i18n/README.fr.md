<a id="introduction"></a>
## Introduction

Le projet est standardisé selon des structures de projets professionnelles, prenant en charge une gestion efficace du code source via Git.

<a id="features"></a>
## Caractéristiques Principales

- Configuration rapide et empaquetage professionnel.
- Configuration légère, facile à maintenir et à étendre.
- Flux de travail de push automatique Git avec le script inclus.

---

## Estructure des Répertoires

```text
JA_Auto_Git/
├── main.py                    # Point d'entrée de l'application
├── run.bat                    # Script de démarrage rapide sur Windows
├── requirements.txt           # Liste des dépendances
├── config.ini                 # Fichier de configuration simple
├── config.json                # Fichier de configuration JSON structuré
├── .gitignore                 # Modèles d'exclusion Git
├── README.md                  # Documentation du projet (ce fichier)
├── LICENSE                    # Fichier de licence
├── ABOUT.txt                  # Description abrégée du projet
├── git_push.bat               # Script de push automatique vers GitHub
│
├── logs/                      # Logs de l'application
│
├── modules/                   # Modules principaux contenant la logique métier
│   # Modules principaux contenant la logique métier
│
└── assets/                    # Ressources statiques de l'application
```
